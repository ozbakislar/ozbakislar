### Profile

I combine data analysis, business intelligence and data science. My starting point is clean preparation and analysis of data with Python and SQL, and its visualisation in Power BI or Tableau, so that business teams can make well-founded decisions. Building on this, I develop machine learning and deep learning models that detect patterns and deliver forecasts, and I deploy them as applications. This is based on a ten-month Data Science Program focused on statistics, machine learning and deep learning.

### Focus Areas

- **Data analysis** – statistics, Python, SQL
- **Business intelligence** – Power BI, Tableau
- **Machine learning** – supervised and unsupervised learning
- **Deep learning** – computer vision, NLP and LLMs
